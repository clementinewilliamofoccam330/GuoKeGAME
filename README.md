## ❓ Frequently Asked Questions

**Do I need a database to run this?**
No. The application handles the connection to the game data for you. You do not need to install MySQL or other backend tools yourself.

**Is this safe for my computer?**
Yes. The software runs locally on your machine and only uses the internet to sync your game lists with our servers.

**Can I run this on a Mac?**
This specific installer works on Windows. For other platforms, check the release page for updates.

**How do I update the software?**
When a new version releases, visit the download link again. Run the new installer over the old version. Your settings will persist.

**What if the app does not open?**
Ensure you have the latest drivers for your graphics card. If you see a security warning, click "More info" and select "Run anyway" to allow the Windows system to start the application.

## 🔧 Troubleshooting

If you encounter issues, try these steps:

1. Restart your computer.
2. Check your firewall settings. Sometimes, the firewall blocks communication between the app and the server.
3. Ensure you have the current version of the Java Runtime Environment installed on your machine.
4. Verify you have sufficient permissions to install software. You may need to ask an administrator if you are on a restricted machine.
5. Clear your temporary files if the interface fails to load images properly.
